# Аудит: Concat MCP Server & Video Generation Fixes

**Дата:** 2026-10-10
**Тип:** Bugfix / Feature
**Изменил:** Antigravity (Hermes/Mavis)
**Причина:** Потеря средств из-за некорректного использования premium API, рассинхронизация расширений в пайплайне и отсутствие интеграции с Concat (задача F7)

---

## 1. Контекст

При попытке сгенерировать ИИ-ролик (cyber-heist), пользователь потратил 960 кредитов ($4.8) из-за того, что скрипт сгенерировал 6 сцен по премиум-тарифу (модель `kling/v2-1-master-text-to-video`, 160 кредитов за сцену). В итоге вместо ожидаемых дешевых роликов были получены дорогие, но из-за бага пайплайна в редактор попали старые видео со стоков YouTube. Помимо этого, попытка открыть сгенерированный `draft.json` в `Concat.app` не увенчалась успехом из-за того, что macOS не сопоставляет формат JSON с данным приложением по умолчанию.

Для решения этих проблем были проведены фиксы в скриптах, пересборка видео, а также реализована задача F7 — создание MCP сервера для интеграции пайплайна с Concat.

---

## 2. Что сделано (по файлам)

### 2.1 `scripts/generate_ai_clips.py`
Скрипт по умолчанию использовал премиум-версию Kling.
- **Исправление:** Дефолтная модель жестко заменена с `kling/v2-1-master-text-to-video` на `kling/v2-1-standard`.
- **Итог:** Будущие генерации защищены от непредсказуемых списаний, тестировать пайплайн можно значительно дешевле.

### 2.2 `py/index/embedder.py` и `library/ai/scenes/*`
Из-за различий в расширениях (`.meta.json` в генераторе и `.metadata.json` в индексаторе) новые ролики просто пропускались, и сборщик (assembler) брал заглушки (YouTube).
- **Исправление:** Метаданные переименованы в `*.metadata.json` с помощью shell-скрипта.
- **Очистка БД:** Выполнен `DELETE FROM clips WHERE source IS NULL;` для очистки "сломанных" записей из SQLite базы.
- **Переиндексация:** `index_library.py` успешно проиндексировал ИИ-файлы с эмбеддингами.

### 2.3 `mcp-server/` (Реализация задачи F7)
Пользователь не смог открыть `draft.json` двойным кликом (macOS не передает JSON в Concat.app). Был необходим MCP сервер для обхода этого ограничения.
- **Инициализация:** В папке `mcp-server` запущен `npm init -y`, установлен `@modelcontextprotocol/sdk`. В `package.json` прописан `"type": "module"`.
- **`index.js`:** Написан StdioServerTransport MCP сервер, который предоставляет два инструмента:
  1. `assemble_episode`: Запускает `assemble_episode.py`.
  2. `open_in_concat`: Вызывает `open -a Concat.app "путь/к/draft.json"`, что обходит проблемы файловых ассоциаций macOS и открывает проект прямо в GUI Concat.
