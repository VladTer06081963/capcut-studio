# Фиксация задач — стандартная процедура закрытия

> Любой AI агент должен знать эту процедуру.

## Активация

Скажи агенту:
- `"фиксируем"` 
- `"фиксация"`
- `"зафиксируй"`

---

## Процедура (5 шагов)

### Шаг 1: OpenSpec Change
Если есть незаархивированный change в `openspec/changes/`:
```bash
# Проверить статус
openspec status --change <name> --json

# Синхронизировать delta specs (если есть)
# Архивировать
mv openspec/changes/<name>/ openspec/changes/archive/YYYY-MM-DD-<name>/
```

### Шаг 2: Аудит
Создать: `summary/audit/<NNN>_<slug>.md`
```markdown
# Аудит: <тема>

## 1. Контекст
## 2. Что сделано
## 3. Статус
```

### Шаг 3: Таски
Создать: `summary/tasks/<NNN>_<slug>.md`
```markdown
# Задачи: <тема>

## Статус: ✅ Done

| ID | Задача | Статус |
|---|---|---|
| 1 | ... | ✅ Done |
```

### Шаг 4: CHANGELOG

Добавить краткую запись в конец `CHANGELOG.md`:

```markdown
- `YYYY-MM-DDTHH:MM:SS+TZ` — Краткое описание изменения.
```

Записи ведутся по нарастающей, от ранних к поздним. Не добавлять секреты, токены и содержимое `.env`.

### Шаг 5: Git
```bash
git add <все изменённые файлы>
git commit -m "<type>: <description>"
git push  # если есть remote
```

---

## Чеклист завершения

- [ ] Аудит создан
- [ ] Таски созданы
- [ ] `CHANGELOG.md` обновлён
- [ ] Git clean (всё закоммичено)
- [ ] OpenSpec change заархивирован (если был)
- [ ] Пуш на GitHub (если remote настроен)

## Быстрый пример

```
Пользователь: фиксация
Агент: По какому вопросу?
Пользователь: добавили логирование
Агент: Фиксирую...

✓ summary/audit/002_logging.md создан
✓ summary/tasks/002_logging.md создан
✓ CHANGELOG.md обновлён
✓ git commit + push
```
