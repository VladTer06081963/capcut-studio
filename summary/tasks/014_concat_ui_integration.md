# Задача F8: Интеграция с UI Concat.app

**Статус:** Выполнено
**Дата:** 2026-10-10
**Связанный аудит:** `summary/audit/014_concat_ui_integration.md`

## Проблема
Сгенерированный пайплайном черновик эпизода (`draft.json`) не открывался и не отображался в приложении Concat.app. Приложение использовало собственный формат JSON, отличный от формата пайплайна, а также читало историю проектов из внутреннего системного кэша `recents.json`, а не из произвольных папок на диске.

## Решение
1. Разработан скрипт-транслятор (`scripts/convert_draft.py`) для преобразования пайплайнового `draft.json` в строго типизированный формат Concat (`concat.json`), включая структуру клипов, медиафайлов и треков.
2. Процесс конвертации интегрирован в MCP-инструмент `open_in_concat` (в `mcp-server/index.js`).
3. Сборка проекта перенесена в штатную директорию (`rendered/`), а путь к ней внедрен в `recents.json`, чтобы интерфейс Concat "узнавал" новые проекты.

## Результат
Теперь пайплайн автономно генерирует полностью нативные проекты, которые мгновенно отображаются на стартовом экране Concat.app.
